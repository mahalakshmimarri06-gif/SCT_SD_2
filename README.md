Task 02: Number Guessing Game
This project is a GUI-based interactive Number Guessing Game developed as part of my software development internship at SkillCraft Technology. The application challenges the user to guess a randomly generated number between 1 and 100, providing feedback on each guess and tracking the number of attempts.

Features
User-Friendly GUI: Built using Python’s tkinter library, featuring a clean and responsive dark-mode interface.

Game Logic: Generates a random number and provides real-time feedback ("TOO HIGH!" or "TOO LOW!").

Interactive Controls:

Submit: Validate your guess.

Reset: Start a fresh game with a new random number.

Exit: Safely close the application.

Success Feedback: Features a celebratory visual overlay upon correctly guessing the number, displaying the total attempts taken.

How to Run
Prerequisites
Python 3.x installed on your machine.
